## 4. 수수료·AI 원가 계산 근거

```

       = $0.00240 + $0.00750
       = $0.00990 × ₩1,474 = ₩14.59 → ₩14.6
```

### 4-2. AI 작품 분석 (Sonnet 4.6)
```

  OpenAI 임베딩 $0.001 + Claude Sonnet 4.6 $0.04 = $0.041
AI 원가 = $0.041 × ₩1,474 = ₩60.43 → ₩60.4
```

### 4-3. AI 작품 분석 (Haiku 4.5 대체)
```
Sonnet 대비 토큰당 1/3 (input $1/$3, output $5/$15)
AI 원가 = $0.041 × (1/3) × ₩1,474 = ₩20.1~20.6 (반올림)
```

### 4-4. 패키지별 수수료
```
Polar = 2.9% × 결제액 + $0.30 고정
고정 = $0.30 × ₩1,474 = ₩442
```
