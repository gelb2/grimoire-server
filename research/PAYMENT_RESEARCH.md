# PAYMENT_RESEARCH.md — 결제 솔루션 전수검사

> 조사일: 2026-03-30
> 목적: PayApp 사용 가능 여부 + 사업자등록 없이 결제를 받을 수 있는 대안 솔루션 조사

---

## 1. PayApp 전수검사

### 1-1. 가맹점 유형

| 유형 | 필요 서류 | 비고 |
|------|----------|------|
| 법인사업자 | 계약서 2부, 법인인감증명서, 사업자등록증, 법인 통장사본 | — |
| 개인사업자 | 계약서 2부, 사업자등록증, 신분증, 통장사본 | — |
| **개인판매자** | 계약서 2부, 신분증, 통장사본 | **사업자등록 불필요** |

출처: [PayApp 구비서류/심사](https://www.payapp.kr/homepage/guide/guide3.html)

### 1-2. 심사 기준

- 결제 후 1~2일 내 서류 제출 → 영업일 3~5일 심사
- **유의업종**: 추가 서류(보험 증빙 등) 요구, 수수료 인상 가능
- **불가업종**: 결제 취소 처리
- 구체적 불가업종 리스트는 공개 페이지에서 확인 불가 — **PayApp 고객센터(1800-3772) 직접 문의 필요**

### 1-3. AI 서비스 관련 리스크

- PayApp 공식 문서에 "AI 생성 콘텐츠"를 명시적으로 금지하는 조항은 **발견되지 않음**
- 다만 "디지털 콘텐츠" 자체가 유의업종에 해당할 가능성 있음
- 사용자가 들은 "AI 사용 시 리젝" 소식은 **카드사(PG사) 측 심사 기준**일 가능성 높음
  - PayApp은 중개 플랫폼이고, 실제 심사는 카드사(NICE, KCP 등)가 수행
  - 카드사마다 AI/디지털 콘텐츠에 대한 정책이 다름

### 1-4. 결론

| 항목 | 가능 여부 |
|------|----------|
| 사업자 없이 PayApp 사용 | **가능** (개인판매자 유형) |
| AI 생성 콘텐츠 판매 | **불확실** (카드사 심사에 따라 다름) |
| 크레딧 충전 모델 | **가능** (디지털 재화 판매로 분류) |
| 지속적 판매 시 사업자등록 필요 | **필요** (국세청 기준: 계속적/반복적 수익 → 사업자 대상) |

**권장 조치**: PayApp 1800-3772에 직접 문의하여 아래 확인:
1. "AI 테마 생성 크레딧 판매"가 불가업종인지
2. 개인판매자로 시작 후 사업자 전환 가능한지
3. 디지털 콘텐츠 판매 시 추가 서류가 필요한지

## 2. 사업자등록 없이 결제 받을 수 있는 대안

### 2-1. 국내 솔루션

| 솔루션 | 사업자 필요 | 수수료 | 특징 | Grimoire 적합성 |
|--------|-----------|--------|------|----------------|
| **PayApp 개인판매자** | X | 3.5~4% | 카드/휴대폰 결제, API 있음 | **높음** — 이미 서버 구현됨 |
| **토스 링크페이** | X | 3.3% | 링크 기반 결제, API 없음 | 낮음 — API 연동 불가 |
| **크티(CTEE)** | X | 0% | 크리에이터 후원 전용 | 낮음 — 크레딧 모델과 안 맞음 |
| **토스페이먼츠** | **O** | 2.9~3.5% | 풀 PG, API 풍부 | 사업자 등록 후 전환 대상 |
| **포트원(PortOne)** | **O** | PG사별 | 멀티 PG 통합 | 사업자 등록 후 전환 대상 |

### 2-2. 해외 솔루션 (사업자 불필요)

| 솔루션 | 사업자 필요 | 수수료 | 특징 | Grimoire 적합성 |
|--------|-----------|--------|------|----------------|
| **Lemon Squeezy** | X | 5% + $0.50 | 디지털 상품 판매 특화, 구독 지원 | **중간** — 수수료 높지만 즉시 시작 |
| **Gumroad** | X | 10% | 디지털 콘텐츠 판매 | 낮음 — 수수료 과다 |
| **Buy Me a Coffee** | X | 5% | 후원 모델 | 낮음 — 한국 Payoneer 지원 종료 |
| **Stripe** | X (해외) | 2.9% + $0.30 | 한국 소재 사업자는 직접 사용 불가 | **불가** — 한국 미지원 |
| **Polar** | X | 4% + $0.40 | MoR(세금대행), 디지털상품/SaaS/구독 범용, API 지원 | **중상** — Lemon Squeezy보다 저렴, MoR 포함 |

### 2-3. 추천 전략

```
[Phase 0 — 현재] PayApp 개인판매자로 시작
    │  사업자등록 없이 카드/휴대폰 결제 가능
    │  이미 서버 구현 완료 (PayApp webhook)
    │
    │  ⚠ 리스크: AI 콘텐츠 심사 거절 가능
    │  → PayApp 고객센터에 사전 확인 필수
    │
[Phase 1 — 수익 발생 시] 사업자등록
    │  개인사업자 (미디어 콘텐츠 창작업 921505)
    │  연 매출 4,800만원 미만 간이과세자 가능
    │
[Phase 2 — 규모 확장 시] 토스페이먼츠 또는 포트원으로 전환
    │  더 낮은 수수료 (2.9~3.5%)
    │  다양한 결제 수단 (카카오페이, 네이버페이 등)
    │  포트원 → 멀티 PG로 A/B 테스트 가능
    │
[대안 — PayApp 거절 시] Polar (1순위) 또는 Lemon Squeezy (2순위)
    Polar: 4% + $0.40, MoR(세금대행), API+웹훅 지원
    Lemon Squeezy: 5% + $0.50, MoR, 디지털상품 특화
    공통: 사업자 불필요, USD 결제 → 환전 필요
    서버 webhook 재구현 필요 (포트 인터페이스 교체만으로 가능)
```

## 3. 세금 관련 유의사항

- **개인판매자라도 소득세 신고 의무 있음** — 종합소득세 (매년 5월)
- 계속적/반복적 수익 발생 시 국세청이 사업자등록 권고 가능
- 후원/기부 명목이라도 실질이 대가성이면 과세 대상
- 크레딧 판매는 "디지털 재화 판매"로 분류 → 부가세 과세 대상 (사업자 등록 시)
